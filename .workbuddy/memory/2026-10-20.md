# 2026-10-20

## 时间轴/任务「同步到今日」三项修复（用户反馈的三个 bug）

背景：用户反馈 ① 同步到今日的时间段在今日页占两条编号（跳号）、完成率分母翻倍；
② 已同步过的内容无法再次同步、换了分组也不更新；③ 任务希望改成「只有勾选且已分组的才同步」。

### 决策（用户拍板）
- 时段已同步 → **更新条目，跟随时间轴**（不再「跳过」，换分组/标题/完成态都写回今日页那条）
- 任务改成**勾选制**：只有「已分组（非其他）+ 有内容」的可勾，已同步过的仍可勾选=更新

### 落地
- `slotSyncService.ts` / `taskSyncService.ts`：`planSlotSync/planTaskSync` 现在返回
  `{ create, update }`；新增 `collectSyncedSlotIds` / `collectSyncedTaskIds`（只认存活条目）。
  `applySlotSync/applyTaskSync` 落地，分组变了用 `nextOrder(list,null)` 挪到新板块顶层末尾；
  内容没变不写（省 updatedAt 推进）。
- `diaryService` / `calendarService`：用 `collectSyncedSlotIds` 排除「已同步时段」的只读投影，
  解决双占编号 + 完成率翻倍。
- `useItemStore.syncFromTasks/syncFromSlots`：改为吃 `TaskSyncPlan/SlotSyncPlan`，
  返回 `{created, updated}`。
- 新增共用 `ui/SyncCheck.tsx`（虚线禁用态=不能选）、`utils/syncMessage.ts`
  （`describeSyncCounts` / `syncButtonLabel`，按钮实时显示「新建 N 项 / 更新 M 项」）。
- `TimelinePage` / `TasksPage`：进入勾选模式，已同步默认勾上且可取消；底部确认栏区分新建/更新。
