## APK 发布（v1.3 为何没有 APK + 修复）
- 根因：打 tag 只是 Git 标签，**≠ 发 GitHub Release**；真正的 APK 发布走 `.github/workflows/mobile.yml` 的「手动 workflow_dispatch + 配齐 4 个签名 secrets」，而我此前从未触发，且原 CI 固定发到 `latest` tag、**不发语义化版本 tag**，所以 v1.3 没有 APK。
- 本机**无 Android SDK**（无 ANDROID_HOME/sdkmanager），本地编不了 APK；无 `gh` CLI/token，不能命令行建 Release → 只能走 CI。
- 修复（commit `782cd2c`，已推送）：`mobile.yml` 手动发布时**同时发两个 Release**——`latest`（稳定链接）+ `v{versionName}`（从 build.gradle 的 versionName 自动推导，即 v1.3），都挂同一份签名 APK。
- 待用户操作：① 在 GitHub repo Settings→Secrets 配 4 个签名 secret（`ANDROID_KEYSTORE_BASE64/PASSWORD/KEY_ALIAS/KEY_PASSWORD`，值见 ANDROID-SIGNING.md）；② Actions→Mobile→Run workflow 手动触发，CI 即出签名 APK 并发布到 latest + v1.3。
- 红线不变：不提交 keystore（已 gitignore）；不换 applicationId；versionCode 每次发版 +1（当前 5）。
