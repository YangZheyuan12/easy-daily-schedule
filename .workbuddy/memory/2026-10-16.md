## 第八轮：键盘飘移修复 + CI 签名 + 备份落点提示（同日）

用户反馈三件事：①导航栏和「添加任务」仍随键盘浮起飘移；②**更新仍要卸载重装**（数据全丢风险）；
③备份导出后找不到文件、导入时也不知去哪选。

**① 键盘飘移**：根因是 `Keyboard.resize='native'`（adjustResize）压缩布局视口 →
fixed 底部元素浮到键盘上方；且此前只有 BottomTabBar 接了 `useKeyboardVisible`，
另外 5 处 fixed 悬浮物（SectionPage/TasksPage/TaskKindPage 添加钮、TimelinePage 操作栏、
UndoBar）裸奔。修法：`useKeyboardVisible.ts` 导出共用 `KEYBOARD_HIDDEN_CLASS`
（translate-160 + opacity-0 + pointer-events-none），六处统一接入；🔴 位置**瞬切**、
只过渡透明度——键盘动画中再叠位移过渡就是「边飘边收」。

**② 覆盖安装**：根因是 **CI 产物签名是随机的**——mobile.yml 在 runner 上打 debug 包，
keystore 不提交 → runner 用每次随机 debug 钥匙签名，与本地固定签名包对不上 → 系统拒装。
本地 build.gradle 的固定签名机制早就配好，缺的只是 CI。修法：mobile.yml 加
「Restore keystore from secrets」（4 个 secrets：ANDROID_KEYSTORE_BASE64 / _PASSWORD /
KEY_ALIAS / KEY_PASSWORD；未配置直接失败不产随机包）+ 构建后打印 APK 证书 SHA-256 指纹。
docs/ANDROID-SIGNING.md 补「CI 配置」一节。⚠️ 已装旧签名包（含此前 CI 随机包）的手机
升级仍要卸载一次：先导出备份 → 卸载 → 装新包 → 合并导入。用户需自行在 GitHub 网页配 secrets。

**③ 备份落点**：`fileBridge.saveTextFile` 改为返回落点描述（原生=系统下载目录、
Web=浏览器下载目录，`Capacitor.isNativePlatform()` 区分）；导出 toast 带位置+文件名；
MePage 备份卡导入按钮下加说明小字。

校验：tsc ✓ ｜ check:layers 194 ✓ ｜ vitest 60 文件 1138 用例 ✓（首次跑报 1 error 未复现，
二次全绿，按纪律以 Test Files=磁盘 find 数为准）｜ build 460.13KB ✓
文档：`docs/ARCHITECTURE.md` §9-K。已提交推送（4 个提交：feat + docs×2 + memory）。

# 第七轮：修复「每次更新必须卸载重装」+ Android CI 红叉（2026-10-16 晚）

## 用户报告
1. 上传 GitHub 有问题，Android CI 没通过
2. （承接上轮）更新 App 仍要卸载重装——数据连续性红线

## 排查结论
- push 本身成功（远端=本地），挂的是 Mobile workflow 的 android job：
  失败在「Restore keystore from secrets」——仓库没配 secrets（上轮设计的硬失败）。
- 更深根因：**本地从未生成 keystore**（android/ 下无 .keystore/keystore.properties），
  本机包用默认 debug 钥匙、CI 包用 runner 随机 debug 钥匙 → 签名永远对不上。

## 修复
- 用 PyCharm JBR 的 keytool 生成 `android/dailyschedule.keystore`
  （RSA2048/10000 天/别名 dailyschedule）+ `android/app/keystore.properties`
  （两文件均被 .gitignore 命中，提交前 `git check-ignore` 验证过）。
  build.gradle 的 debug/release 从此共用这把钥匙 → 本地构建签名固定。
- versionCode 2→3（换签名=新发布线）。
- mobile.yml 改探测式：「Restore keystore (optional)」没配 secrets → present=false +
  ::warning:: → 只跑 debug 构建验证、发布步骤全跳过、job 绿；配了 → assembleRelease
  出签名包上传。🔴 绝不再产出随机签名发布包。
- docs/ANDROID-SIGNING.md 标注 keystore 已生成 + CI 新行为 + 验证指纹
  （SHA256 48:AD:DE:AC:...:E7:87）。
- YAML 用 pyyaml 验证结构（venv 建在 binaries/python/envs/default，Scripts/ 路径）。

## 结果
提交 5758508 推送成功；Mobile run 38897053751 双 job 全绿
（android: keystore 探测 success → build gate success → 发布步骤 skipped，无产物）。

# 第九轮：修复「添加弹窗闪一下」+ 备份导出真正落地（2026-10-16 深夜）

## 用户报告
1. 期限任务/长时目标点进去后，添加弹窗闪一下（怀疑导航栏没固定）
2. 导出日程在手机里找不到文件夹（怀疑没写入权限）

## 弹窗闪动——根因（与导航栏无关，三层时序叠加）
1. `TaskKindComposer` 的 input `autoFocus`（全项目唯一一处）→ 键盘在 Sheet 入场动画
   （m-sheet-up 280ms）进行中就弹出；
2. Capacitor `Keyboard.resize=native`（adjustResize）连布局视口一起压缩 →
   fixed inset-0 的抽屉容器在半空中变高度；
3. `useKeyboardAvoid` 在键盘弹起过渡帧算出瞬时小 offset（innerHeight 与 vv.height
   变化不同步）写进 `--keyboard-offset` → 抽屉 paddingBottom/maxHeight 跳变。
板块页 ItemSheet 无 autoFocus（键盘等用户点输入框）所以不闪——吻合用户观察。

修复：① autoFocus 属性移除 → ref + 延迟 280ms focus（仅新增态，编辑态不抢焦点）；
② useKeyboardAvoid 加 OFFSET_THRESHOLD=120 阈值（与 KEYBOARD_THRESHOLD 同源），
小偏移写 0px。测试 4+5 条，负向验证全红后恢复。

## 备份导出——真相：`<a download>` 在 Capacitor WebView 根本不落地
- WebView 无 DownloadListener → Blob URL 点击无反应，文件从未写盘（§9-K.3 只加了
  提示文案，提示的是假位置）。
- Filesystem 插件公共目录也走不通：官方文档确认 ExternalStorage Android 11+ 不可访问、
  Documents 11+ 仅限 App 自建文件。
- 修复：自写本地插件 SaveFilePlugin.java（@CapacitorPlugin "SaveFile"）：
  API 29+ MediaStore.Downloads（IS_PENDING 写流再发布，免权限，媒体库立即可见）；
  API 24-28 File 直写 + manifest WRITE_EXTERNAL_STORAGE maxSdk=28。
  MainActivity registerPlugin（cap sync 不覆盖 MainActivity）。TS 侧
  `platform/saveFilePlugin.ts` 封装；`fileBridge.saveTextFile` 改 async，
  android 走插件（返回「系统下载目录」文案）、Web/iOS 维持 a download；
  原生失败向上抛 → store 变失败 toast。MePage 说明改「App 内看不到，去文件管理 App」。
- 🔴 装了 @capacitor/filesystem 试过后卸载（方案不同），依赖保持干净。
