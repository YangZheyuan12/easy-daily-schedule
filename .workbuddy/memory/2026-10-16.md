# 2026-10-16（第六轮：去进度显示 + 展开态跨页保持；第七轮：组头「N项」计数回归）

## 用户需求（两条）
1. 「今日」页删掉「0/3」这样的进度条；点进「工作」编辑页后显示的「完成 0%」也删掉。
2. 展开/收起状态要跨页保持：任务页展开期限任务 → 切去别页再回来仍是展开的，其它展开收起同理。

## 实现
**去进度显示**（今日 + 工作两个页面，用户点名的范围）：
- `DiaryList` 组头去掉 `{done}/{total}`（连同 topEntries/doneCount/totalCount 计算与注释）。
- `SectionPage` 副标题只剩日期，删 `percent` useMemo + `toPercent` import。
- `WeekSectionBoards` 田字格格头去掉 x/y。
- `TreeRow` 去掉展开态的子项 x/y；保留折叠态「藏着几条」徽标（计数非进度）。
- `SectionWeekPage` 副标题的「完成 x/y」一并撤掉（同类显示，补一致性）。
- 保留：`progressService`/日历摘要卡口径、`treeService.childrenProgress`（字段+口径测试在，仅无 UI 消费者，类型注释已写明）、任务页副标题与进度条（用户未提，刻意没动）。

**展开态跨页保持**：`useUiStore` 加 `expansions: Record<string, boolean>` + `setExpanded`、
`dismissedReminder` + `dismissReminder`（横幅语义相反，单列）；新建 `hooks/useExpanded(key, defaultOpen)`
（不落盘、刷新重置，与 drawerItemId/toasts 一致）。接入：TaskPreviewCard（新增必填 prop `expandKey`，
DeadlineCard 传 `tasks:deadline`、GoalCard 传 `tasks:goal`）、CollapsibleCard（必填 `expandKey`，MePage 六卡
`me:*`）、SelfStatusCard（`today:self-status`）、SectionRow（`me:section:{key}`）、ImageStrip
（`images:{itemId}`，默认展开）、ReminderBanner（dismiss 键内容派生，新时段到期自动重现）。
CollapsibleCard 原「状态不持久化是刻意的」注释按新决策改写。

## 第七轮（同日追改）：组头「N项」计数回归

用户看完去进度效果后反馈「光秃秃」：今日页组头后加一行小字「0项」，点进去的编辑页面也显示，
数量来自分类下面的事件数。结论：完成率不回来，**纯计数**回来。

- `DiaryList.SectionGroup` 组头：`topCount = visibleEntries` 里 item+timeSlot 数（只数可见，
  隐藏/已同步不计；子项不计；与日历摘要卡同口径）→ 组名右侧 caption 弱化色「N项」。
- `InspirationGroup` 组头：「N 条 / —」统一为「N项」（空也显示 0项）。
- `SectionPage` 副标题：`日期 · N项`，N = 该板块当天**顶层**条目数（时间段只在今日页投影故不计，
  两页可能差 1，刻意：各数各页看得见的事件）。
- 🔴 只放数量不放完成率；`progressService` 口径与测试原样保留。

测试：新增 `diaryListGroupCount.test.ts`（5）+ `sectionPageSubtitle.test.ts`（3）；
负向验证：口径改成含子项 → 「子项不计入」红；副标题退回纯日期 → 3 条全红。
