## iOS 真机验证路径（用户有 iPhone 15，无 Mac）
- 核对结论：iOS 导出=Filesystem→Documents（靠 `UIFileSharingEnabled` 在「文件」App 可见）；
  分享=@capacitor/share（iOS 实现确实吃 `files`，转 file URL 进 activityItems）；
  导入=`<input type="file">`（部署目标 iOS 15.0，WKWebView 支持）；快照=Documents/Backups。
  **全部只在代码层核对过，零真机验证。**
- 🔴 Windows 无 Mac = 出不了原生包，这是硬约束。三条路：Safari 局域网直连（今晚可做，
  vite 已 `host:true`）/ 借 Mac 或云 Mac + 免费 Apple ID 签名（7 天重签）/ TestFlight（688 元每年）。
- Safari 直连注意：导出走 `<a download>` 落在「文件」App→下载，**不是**原生壳行为，别误当验证；
  Safari 会清理长期不访问站点的 IndexedDB（加到主屏幕可豁免）。
- 已把这些写进 `docs/MOBILE-APP-MIGRATION.md` 的「没有 Mac 也能先验证」一节。

- 新增 `public/manifest.webmanifest`、`public/sw.js`、`src/platform/pwaBridge.ts`；
  `index.html` 补 manifest link + `apple-touch-icon` + `mobile-web-app-capable` +

- `scripts/tools/make-app-icon.mjs` 现在一并出 `public/apple-touch-icon.png(180)` /
  `pwa-192` / `pwa-512`（同一张 SVG，去 alpha）。
- 🔴 SW 三道闸：原生壳永不注册 / 开发模式不注册 / 失败静默。理由：Capacitor 自己管发版，
  SW 再缓存一层 = 「装新版跑旧代码」且只在清缓存后消失，难查。
- SW 策略：导航 network-first（发版即生效，**不用维护缓存版本号**）+ 资源 stale-while-revalidate。
- 局域网 http 下浏览器不给 SW → Safari 直连测不到离线能力，但图标/全屏不依赖 SW。
- 验证：`npm run verify` 75 文件 1294 用例全过；`dist/` 含 manifest+sw+3 图标；
  子路径部署（`VITE_BASE_PATH=/ds/`）下 manifest 路径会被 Vite 正确重写为 `/ds/manifest.webmanifest`。
  ⚠️ Windows Git Bash 会把 `/ds/` 转成盘符路径造成假象，需 `MSYS_NO_PATHCONV=1` 才是真实结果。
