## 🔴 AI 对话回答「杂乱无章」的根因与修复（A+B，未提交）
根因有两条，**主因不在 prompt，在渲染层**：
1. **换行被 CSS 抹平（主因）**：`AiChatPanel` 的 `ChatBubble` 是裸 `<div>{content}</div>`，全项目
   没有一处 `whitespace-pre-line`/`pre-wrap` → 模型输出的 `\n` 被 HTML 塌成空格，结构全丢，
   看起来就是一大段连续文字；叠加模型输出的 `- `、`**` 原样显示更像乱码。
2. **旧 prompt 自己在要求写大段文字**：旧版写着「不要用列表堆砌；除非用户明确要清单，
   否则用连贯的段落」——这句正是产出流水账的原因，已删。

修复：
- `components/ai/AiChatPanel.tsx`：气泡加 `whitespace-pre-line break-words`（🔴 删除这行就会退回旧症状）。
- `platform/ai/prompt.ts` 的 `AI_CHAT_SYSTEM_PROMPT` 重写为**结构契约**：第一句给结论（≤30 字、
  不复述问题不寒暄）→ 2~3 条依据**每条单独一行 `- ` 开头且必须带快照数字** → 结尾 1 条 ≤40 字
  的具体建议（禁「保持坚持」类空话）；长度 120~200 字（说「分析」时 ≤300 字，按结论/完成率/趋势/
  短板/建议各占一行）；**只输出纯文本，禁 Markdown 标题/加粗/星号/代码块/表格/emoji**；
  数据纪律：数字只能来自快照、百分比取整、`daysWithData < 3` 或 section/task 总数都为 0 时
  第一句就明说「数据还太少」不许硬编、不许对用户说「快照/JSON/字段/聚合」。
- `buildChatUserPrompt` 末句改为「按系统指示的结构，用简体中文只输出回答正文，不要任何开场与结束语」。
- 新增 `platform/ai/__tests__/prompt.test.ts`（9 用例）锁契约：结论先行、必须带数字、禁 Markdown、
  数据不足要明说、**断言不再包含「连贯的段落」「不要用列表堆砌」**、分析 prompt 仍要求严格 JSON。
- `AI_SYSTEM_PROMPT`（结构化分析那条 JSON 通道）**保持不动**。
- 待办 C（未做，效果待观察）：把输入从 `JSON.stringify(snapshot, null, 2)`（30 天 200+ 行）
  换成紧凑摘要（区间/整体/近 7 天/最差 3 天），token 少一个量级、模型更易抓重点。
- 验收：tsc 0 错；check:layers 282 文件过；全量 **94 文件 / 1425 用例全绿**（磁盘 94=94）。
  🔴 又一次踩 EPERM：3 文件并跑只报 2 个（`prompt.test.ts` 被静默丢），单独重跑 9 用例全绿才作数。
