
## 发布为网站（2026-10-28 凌晨）
- 用户要把「易记日程 / ezschedule-daily」变成一个可在 WorkBuddy 中体验的网站。
- 方式：纯前端静态托管（数据在 IndexedDB，原生能力已 `isNativePlatform()` 兜底），`vite build` 以
  `VITE_BASE_PATH=./`（相对路径 base）产出 `dist/`，再用 `workbuddy_sites_deploy` 以 `language: static`
  部署 `dist/`（避开 Vite dev/preview 的 host 校验问题）。
- 结果：`shareLink = https://ezschedule-daily.app.workbuddy.host/?sharecode=CVENHQWRQD`，verified=true，
  deployedAs=web-page，domainPrefix=ezschedule-daily，appName=易记日程。genie 标记
  `.wbapp_1W0QSX56J4RpuCg1sLtwg8.genie`。
- 提示：网站用浏览器本地 IndexedDB（各访客数据独立）；AI 助手需用户自填 API Key（直连外部端点，受 CORS 约束）。
